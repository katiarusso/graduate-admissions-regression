# Predicting Graduate Admissions Outcomes with Multivariate Regression

This project explores the key factors influencing graduate school admission outcomes using real-world applicant data. By applying multivariate linear regression, we modeled the relationship between academic and personal variables and the probability of admission.

## Project Overview

We analyzed a dataset of 500 graduate school applications and developed a regression model to investigate how features like GRE, TOEFL, CGPA, research experience, and university rating affect admission chances. The project includes:

- Data cleaning and exploratory visualization
- Multiple linear regression and diagnostic testing
- Interaction effect analysis (e.g. research × university rating)
- Model selection using a step-down approach
- Validation through k-fold cross-validation

The final report was written in LaTeX, and all analyses were carried out in R.
